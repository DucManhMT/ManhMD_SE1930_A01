## 1. Mục Tiêu & Yêu Cầu Kỹ Thuật

Triển khai chế độ Ngoại tuyến (Offline Mode) cho Frontend Web App:
1. Tự động phát hiện khi Core API hoặc dịch vụ mạng gặp sự cố (mất kết nối, timeout, HTTP 500-504), chuyển trạng thái `IsOffline = true`.
2. Tự động đọc danh mục, thẻ tin, bài viết từ bộ nhớ đệm / file snapshot JSON cục bộ do Background Worker lưu trữ để trang vẫn tải mượt mà.
3. Hiển thị Banner cảnh báo màu vàng nổi bật trên toàn bộ các trang (`_Layout.cshtml`).
4. Khóa cứng toàn bộ các thao tác thêm, sửa, xóa (CRUD), nhân bản, tải ảnh ở cả hai tầng: Giao diện người dùng (disabled nút + chặn submit) và Tầng Client/Server (ném ngoại lệ `ServiceUnavailable` với thông báo tiếng Việt rõ ràng).
5. Tự động khôi phục `IsOffline = false` khi Core API hoạt động bình thường trở lại.
