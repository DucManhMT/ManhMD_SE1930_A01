## 2. Các Thay Đổi Mã Nguồn Đã Thực Hiện

### 2.1. Cấu hình dịch vụ & Models
- **`FUNewsManagement_FE/appsettings.json`**:
  - Bổ sung khối `ApiEndpoints` và chuẩn hóa khối `Api` chứa URLs cho `CoreApi`, `AnalyticsApi`, và `AiApi`.
- **`FUNews.Client.DataAccess/Models/`**:
  - `LoginResponseApiModel.cs`: Bổ sung `AccessToken` và `RefreshToken`.
  - `RefreshTokenRequestApiModel.cs`: Model gửi request xoay vòng và thu hồi token.
  - `AnalyticsModels.cs`: DTOs cho Analytics API (`AnalyticsDashboardApiModel`, `TrendingArticleApiModel`, `RecommendedArticleApiModel`).
  - `AiModels.cs`: DTOs cho AI API (`TagSuggestionResponseApiModel`, `TagFeedbackRequestApiModel`).

### 2.2. DelegatingHandler & Polly Retry Policy
- **`FUNews.Client.DataAccess/Handlers/AuthTokenDelegatingHandler.cs`**:
  - Lấy Bearer Token từ `ITokenProvider` gán vào header.
  - Bỏ qua các endpoint xác thực (`/api/auth/login`, `/api/auth/refresh`) để tránh vòng lặp đệ quy.
  - Khi nhận 401 Unauthorized: Kích hoạt `SemaphoreSlim` đồng bộ hóa, gọi `POST /api/auth/refresh` qua `AuthRefreshClient` độc lập.
  - Cập nhật token mới vào Session qua `_tokenProvider.SaveTokens(...)`.
  - Tự động clone lại request gốc và retry với token mới.
  - Khi refresh thất bại: Tự động dọn sạch token qua `_tokenProvider.ClearTokens()`.
- **`FUNews.Client.DataAccess/Policies/PollyPolicies.cs`**:
  - Triển khai `GetGetRetryPolicy()` bằng `HttpPolicyExtensions.HandleTransientHttpError().WaitAndRetryAsync(...)` với 3 lần thử, thời gian 1s, 2s, 4s + Jitter.
  - Triển khai `GetSelectableRetryPolicy(HttpRequestMessage request)`: Áp dụng retry nếu là GET; dùng `Policy.NoOpAsync()` cho POST/PUT/DELETE.

### 2.3. 3 Typed HttpClients & Dependency Injection
- **`FUNews.Client.DataAccess/Clients/`**:
  - `ICoreApiClient.cs` & `CoreApiClient.cs`: Kế thừa `FUNewsApiClient`, bổ sung `RefreshTokenAsync` và `LogoutAsync`.
  - `IAnalyticsApiClient.cs` & `AnalyticsApiClient.cs`: Client cho Dashboard, Trending, Recommend và Export Excel.
  - `IAiApiClient.cs` & `AiApiClient.cs`: Client cho Suggest Tags và Tag Feedback.
- **`FUNews.Client.DataAccess/Extensions/ClientDataAccessServiceCollectionExtensions.cs`**:
  - Đăng ký `AuthRefreshClient` độc lập.
  - Đăng ký 3 Typed HttpClients gắn `AuthTokenDelegatingHandler` và Polly Policy.
  - Đăng ký alias `IFUNewsApiClient -> ICoreApiClient` để bảo toàn tương thích 100% với các service và Razor Pages A01.
- **`FUNewsManagement_FE/Program.cs`**:
  - Nạp 3 URLs từ configuration và gọi `AddFUNewsClientDataAccess(coreApiUrl, analyticsApiUrl, aiApiUrl)`.

### 2.4. Tích hợp Trang Đăng Nhập & Đăng Xuất
- **`FUNewsManagement_FE/Pages/Login.cshtml.cs`**:
  - Lưu cặp `AccessToken` và `RefreshToken` vào Server-side Session qua `_tokenProvider.SaveTokens(...)`.
- **`FUNewsManagement_FE/Pages/Logout.cshtml.cs`**:
  - Thu hồi Refresh Token trên Core API qua `_coreApiClient.LogoutAsync(...)` trước khi hủy session.
