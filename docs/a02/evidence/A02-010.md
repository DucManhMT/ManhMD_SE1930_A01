## 1. Mục Tiêu & Yêu Cầu Đã Triển Khai

1. **Kiến trúc dịch vụ độc lập `FUNewsManagement_AIAPI` (port 7003):**
   - Hoạt động như một microservice riêng biệt, không truy cập trực tiếp CSDL SQL Server của Core API.
   - Xác thực phân quyền qua JWT Bearer: `[Authorize(Roles = "Staff,Admin")]`.
   - Kết nối tới Core API (`https://localhost:7001`) qua `ITagCatalogClient` để đồng bộ danh mục Tags và cache trong bộ nhớ (`IMemoryCache`).
2. **Thuật toán bóc tách từ khóa tự động (Keyword Extraction Engine):**
   - Triển khai trong [TagExtractorService.cs](file:///e:/IDE/My_Project/PRN232/ASS01/ManhMD_SE1930_A01/FUNewsManagement_AIAPI/Services/TagExtractorService.cs).
   - Chuẩn hóa văn bản: Chuyển về chữ thường, xử lý dấu câu, giữ lại các ký hiệu kỹ thuật như `#`, `+`, `.`, `-` (hỗ trợ tag C#, .NET, C++...).
   - Lọc bỏ Stop-words tiếng Việt và tiếng Anh thông dụng ("và", "là", "của", "những", "các", "the", "and"...).
   - Đếm tần suất xuất hiện chính xác của tag trong nội dung.
   - Tính toán điểm tin cậy `confidence` từ 0.0 đến 1.0 dựa trên tần suất xuất hiện và độ dài cụm từ.
   - **Chạy cục bộ 100% bằng thuật toán C#**: Không phụ thuộc cứng vào bất kỳ OpenAI API Key nào từ bên ngoài (AC 3). Đồng thời hỗ trợ cờ cấu hình `AiSettings:UseOpenAI` để mở rộng khi có nhu cầu.
3. **Cơ chế Bộ nhớ học (Learning Cache):**
   - Triển khai trong [LearningCacheService.cs](file:///e:/IDE/My_Project/PRN232/ASS01/ManhMD_SE1930_A01/FUNewsManagement_AIAPI/Services/LearningCacheService.cs).
   - Lưu trữ cặp `(TagId, FrequencyCount)` trong bộ nhớ thread-safe `ConcurrentDictionary<int, int>` và bền vững hóa (persistence) ra tệp JSON `learning-cache.json`.
   - Khi nhân viên biên tập thực tế chọn tag để gắn vào bài viết (`POST /api/ai/tag-feedback`), hệ thống tăng `FrequencyCount` của tag đó.
   - Trong các lần gợi ý tiếp theo, những tag có tần suất chọn cao trong Learning Cache sẽ được cộng thêm trọng số ưu tiên (`GetBonusWeight`) tối đa lên tới +0.25 để đẩy tag đó lên đầu danh sách gợi ý.
4. **Các Endpoints Web API:**
   - `POST /api/ai/suggest-tags`: Tiếp nhận `{"content": "..."}`, trả về danh sách thẻ tin gợi ý `suggestedTags` (kèm alias `tags`) gồm `tagId`, `tagName`, `confidence`.
   - `POST /api/ai/tag-feedback`: Tiếp nhận `tagId` hoặc mảng `selectedTagIds`, ghi nhận phản hồi vào Learning Cache.

## 2. Các File Mã Nguồn Đã Tạo & Cập Nhật

### 2.1. Phía AI API
- `FUNewsManagement_AIAPI.csproj`: Thêm package `Microsoft.AspNetCore.Authentication.JwtBearer` (`8.0.10`).
- `appsettings.json`: Cấu hình `Jwt`, `ApiSettings:CoreApiUrl`, và `AiSettings`.
- `Models/AiTagDtos.cs`:
  - `AiTagRequestDto`: DTO đầu vào cho nội dung bài viết.
  - `TagSuggestionDto` & `TagSuggestionResponseDto`: DTO trả về gợi ý tag và điểm confidence.
  - `TagFeedbackRequestDto` & `TagFeedbackResponseDto`: DTO tiếp nhận và phản hồi feedback học tập.
  - `CoreTagDto`, `CoreODataResponse<T>`: DTO tiếp nhận dữ liệu từ Core API.

- `Services/ILearningCacheService.cs` & `LearningCacheService.cs`: Dịch vụ lưu trữ và cập nhật trọng số tag với file persistence `learning-cache.json`.
- `Services/ITagExtractorService.cs` & `TagExtractorService.cs`: Thuật toán bóc tách từ khóa, tính confidence và bonus weight từ Learning Cache.
- `Controllers/AiTagController.cs`: Controller cung cấp 2 endpoints `/api/ai/suggest-tags` và `/api/ai/tag-feedback`.
- `Program.cs`: Cấu hình JWT Bearer, MemoryCache, Singleton Learning Cache, Scoped Extractor, HttpClient và Swagger với nút Authorize.
- Đã dọn dẹp các file mẫu: `WeatherForecast.cs`, `WeatherForecastController.cs`.
