## 1. Mục Tiêu & Yêu Cầu Đã Triển Khai

1. **Endpoint `GET /api/analytics/dashboard` (`[Authorize(Roles = "Admin")]`):**
   - Tiếp nhận query params: `startDate`, `endDate`, `categoryId`, `authorId`, `status`.
   - Tính toán và trả về DTO chuẩn phân tích:
     - `totalArticles`: Tổng số bài viết thỏa mãn bộ lọc.
     - `activeArticles`: Số bài viết kích hoạt (`NewsStatus == true`).
     - `inactiveArticles`: Số bài viết vô hiệu hóa (`NewsStatus == false`).
     - `articlesByCategory` / `byCategory`: Thống kê số lượng bài theo từng chuyên mục `[{"categoryId": 1, "categoryName": "...", "count": X}, ...]`.
     - `byStatus`: Thống kê số lượng bài theo trạng thái `[{"status": "Active", "count": A}, {"status": "Inactive", "count": B}]`.
     - `articlesByPeriod`: Thống kê số lượng bài theo chu kỳ thời gian (tháng `yyyy-MM`).
2. **Endpoint `GET /api/analytics/trending` (`[Authorize(Roles = "Admin")]`):**
   - Tiếp nhận query param: `limit` (mặc định 10, giới hạn 1 – 100).
   - Truy vấn số lượt đọc trong bảng `NewsView` qua Core API (`GET /api/news/views/stats`), kết hợp với danh sách bài viết.
   - Sắp xếp giảm dần theo lượt xem (`ViewCount`) và ngày tạo (`CreatedDate`).
   - Trả về danh sách bài viết kèm số view: `[{"newsArticleId": "...", "newsTitle": "...", "viewCount": 500, "createdDate": "...", "categoryName": "..."}, ...]`.
3. **Endpoint `GET /api/recommend/{id}` (`[AllowAnonymous]`):**
   - Tiếp nhận `id` của bài viết đang xem.
   - Lấy thông tin bài viết gốc (Category và Tags). Nếu không tồn tại bài viết, trả về HTTP 404 ProblemDetails.
   - Lọc các bài viết khác: loại trừ chính bài viết gốc, chỉ lấy bài có trạng thái `Active`, có cùng `CategoryId` hoặc có ít nhất 1 Tag chung.
   - Tính điểm ưu tiên (Score dựa trên trọng số Category và số Tag chung), sắp xếp giảm dần.
   - Giới hạn trả về tối đa **3 bài viết liên quan**.
4. **Endpoint `GET /api/analytics/export` (`[Authorize(Roles = "Admin")]`):**
   - Sử dụng thư viện `ClosedXML` tạo file Excel `.xlsx` gồm 2 sheet:
     - Sheet 1: "Thống Kê Tổng Quan" (Tiêu đề báo cáo, thời gian xuất, thông tin bộ lọc, KPI Box tổng quan, bảng chuyên mục, bảng trạng thái).
     - Sheet 2: "Chi Tiết Bài Viết" (Mã bài viết, Tiêu đề, Chuyên mục, Tác giả, Ngày tạo, Trạng thái, Lượt xem).
   - Định dạng bảng chuẩn corporate: màu tiêu đề xanh navy (#1F4E79), chữ trắng in đậm, viền bảng mỏng, tự động căn lề cột (`AdjustToContents()`).
   - Trả về binary stream định dạng `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`.
5. **Đảm bảo nguyên tắc kiến trúc phân tán:**
   - Analytics API là dịch vụ Web API độc lập (`FUNewsManagement_AnalyticsAPI.sln`, port 7002).
   - Tuyệt đối không kết nối trực tiếp CSDL SQL Server của Core API.
   - Giao tiếp dữ liệu qua `ICoreDataClient` (`CoreDataClient` dùng `HttpClient` gọi Core API).
   - Tự động chuyển tiếp Authorization Bearer Header từ HttpContext của Admin sang Core API.
   - Tích hợp xác thực JWT Bearer với Issuer `FUNewsApi`, Audience `FUNewsWeb`.
   - Cấu hình Swagger UI kèm Bearer token authorization.
