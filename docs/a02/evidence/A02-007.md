## 1. Mục Tiêu & Yêu Cầu

1. **Xây dựng endpoint tải lên ảnh bài viết phía Core API:**
   - Endpoint: `POST /api/news/{id}/image` (yêu cầu quyền `Staff`).
   - Tiếp nhận file multipart qua `IFormFile file`.
   - **Validation chặt chẽ:**
     - Dung lượng tối đa: Không vượt quá 5MB. Nếu vượt quá, ném `PayloadTooLargeException` trả về HTTP 413 Payload Too Large.
     - Phần mở rộng (Extension): Chỉ chấp nhận `.jpg`, `.jpeg`, `.png`, `.webp`. Nếu không đúng, ném `UnsupportedMediaTypeException` trả về HTTP 415 Unsupported Media Type.
     - Magic Bytes kiểm tra thực tế phần đầu nhị phân file (PNG: `89 50 4E 47`, JPEG: `FF D8 FF`, WEBP: `52 49 46 46` - RIFF), ngăn chặn giả mạo đuôi file.
     - Kiểm tra file rỗng (0 bytes) trả về HTTP 400 ValidationException.
     - Kiểm tra bài viết tồn tại (HTTP 404 NotFoundException).
   - **Lưu trữ an toàn:** Lưu file vào thư mục `wwwroot/uploads/news/` với tên file GUID ngẫu nhiên (`{guid:N}{ext}`).
   - Cập nhật đường dẫn tương đối `/uploads/news/{guid}.ext` vào cột `NewsImage` trong bảng `NewsArticle` của SQL Server.
   - Trả về JSON: `{"imageUrl": "/uploads/news/{guid}.ext"}`.
2. **Cấu hình Static Files:**
   - Kích hoạt `app.UseStaticFiles()` trên Core API để client có thể truy cập ảnh đã tải lên.
3. **Phía Frontend (FE Client & UI):**
   - Bổ sung thuộc tính `NewsImage` vào `NewsArticleApiModel`.
   - Cung cấp phương thức `UploadNewsImageAsync` trên `IFUNewsApiClient`, `CoreApiClient` và `INewsClientService`.
   - Cập nhật **Modal Tạo bài viết (`modalCreateNews`)**: Bổ sung input file chọn ảnh, kiểm tra dung lượng client (< 5MB) và xem trước (preview) ảnh trước khi lưu.
   - Cập nhật **Modal Sửa bài viết (`modalEditNews`)**: Hiển thị ảnh hiện tại, cho phép chọn ảnh mới kèm preview và upload cập nhật.
   - Cập nhật **Modal Chi tiết bài viết (`modalNewsDetail`)**: Hiển thị ảnh minh họa bài viết.
   - Cập nhật **Trang Bảng tin công khai (`Pages/News/Index.cshtml`)**: Hiển thị ảnh bài viết trên thẻ tin tức.
   - Cập nhật **Trang Chi tiết bài viết (`Pages/News/Detail.cshtml`)**: Hiển thị ảnh nổi bật (featured image) kích thước lớn.
