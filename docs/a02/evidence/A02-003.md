## 1. Mục Tiêu & Kết Quả Đạt Được

1. **Bảng Cơ Sở Dữ Liệu `RefreshToken`:**
   - Đã tạo bảng `RefreshToken` trong SQL Server thông qua bản vá `database/patches/005_assignment02_migration.sql`.
   - Hỗ trợ lưu trữ Refresh Token an toàn cho cả DB accounts (Staff, Lecturer) và Admin config (qua `UserEmail`).
   - Có cơ chế đánh dấu `IsRevoked`, thời hạn `ExpiresAt` và theo dõi xoay vòng `ReplacedByToken`.
2. **Nâng cấp `AuthService`:**
   - Sinh Refresh Token ngẫu nhiên bằng bộ sinh số bảo mật `RandomNumberGenerator` (64 bytes cryptographic string).
   - Tự động lưu và trả về cặp Token (`accessToken` + `refreshToken`) khi gọi `POST /api/auth/login`.
   - Thực thi cơ chế **Token Rotation**: Khi gọi `POST /api/auth/refresh`, token cũ lập tức bị thu hồi (`IsRevoked = true`) và cấp cặp token mới.
   - Ngăn chặn việc tái sử dụng token đã thu hồi (trả về HTTP `401 Unauthorized`).
3. **Endpoint `POST /api/auth/logout`:**
   - Thu hồi Refresh Token khi người dùng đăng xuất.
