## 3. Các bước triển khai
1. Thiết lập `FUNewsManagement_CoreAPI.sln`: Kế thừa toàn bộ cấu trúc dự án từ `ManhMD_SE1930_A01_BE` (Controllers, BusinessLogic, DataAccess).
2. Thiết lập `FUNewsManagement_FE.sln`: Kế thừa toàn bộ cấu trúc dự án từ `ManhMD_SE1930_A01_FE` (Pages, Client.BusinessLogic, Client.DataAccess).
3. Khởi tạo `FUNewsManagement_AnalyticsAPI.sln`: Dự án ASP.NET Core Web API .NET 8 mới, cấu hình Swagger, port mạng độc lập (ví dụ `7002`).
4. Khởi tạo `FUNewsManagement_AIAPI.sln`: Dự án ASP.NET Core Web API .NET 8 mới, cấu hình Swagger, port mạng độc lập (ví dụ `7003`).
5. Đảm bảo cả 4 solutions biên dịch thành công độc lập và không có tham chiếu dự án (ProjectReference) chéo trái phép.
