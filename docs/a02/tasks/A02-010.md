## 1. Mục tiêu
Xây dựng dịch vụ Web API độc lập `FUNewsManagement_AIAPI` chịu trách nhiệm phân tích văn bản bài viết, tự động gợi ý danh sách Thẻ tin (Tags) kèm điểm tin cậy (Confidence Score) và duy trì cơ chế Learning Cache để ghi nhớ các tag được người dùng ưa chuộng chọn nhiều.

---

- `FUNewsManagement_AIAPI/Services/LearningCacheService.cs`
- `FUNewsManagement_AIAPI/Models/` (`AiTagRequest.cs`, `AiTagResponse.cs`, `TagFeedbackRequest.cs`)

---

## 3. Các bước triển khai
1. Xây dựng thuật toán bóc tách từ khóa (Keyword Extraction Engine) trong `TagExtractorService`:
   - Chuẩn hóa văn bản đầu vào: Chuyển chữ thường, loại bỏ các ký tự đặc biệt, ngắt câu và tách từ.
   - Loại bỏ Stop-words tiếng Việt/Anh thông dụng.
   - Trích xuất các cụm từ quan trọng (Unigrams và Bigrams).
   - So khớp các cụm từ này với danh mục Tags đang có trong hệ thống (lấy từ Core API hoặc cache danh mục).
   - Tính toán điểm tin cậy `confidence` từ 0.0 đến 1.0 dựa trên tần suất xuất hiện và độ dài cụm từ.
   - Hỗ trợ cờ cấu hình `UseOpenAI: true/false` trong `appsettings.json` để có thể linh hoạt chuyển sang OpenAI API nếu người dùng cung cấp Key.
2. Xây dựng `LearningCacheService`:
   - Lưu trữ và cập nhật số lần mỗi Tag được người dùng chọn thực tế vào bảng `TagLearning` hoặc file JSON cục bộ `learning-cache.json`.
   - Khi tính toán gợi ý, cộng thêm điểm thưởng (Weight bonus) cho những Tag có lịch sử được chọn nhiều trong Learning Cache để đưa lên top đầu.
3. Xây dựng 2 endpoints:
   - `POST /api/ai/suggest-tags`: Nhận JSON `{"content": "..."}`, trả về danh sách `suggestedTags` có `tagId`, `tagName`, `confidence`.
   - `POST /api/ai/tag-feedback`: Nhận danh sách các `selectedTagIds` mà người dùng thực tế đã chọn, tăng bộ đếm trong Learning Cache.
