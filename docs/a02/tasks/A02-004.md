# Task A02-004 — Frontend: Quản Lý 3 HttpClients, DelegatingHandler & Polly Retry

- **Hạng mục:** Frontend Web App

## 1. Mục tiêu
Thiết lập cơ chế giao tiếp mạng chuyên nghiệp cho Frontend: Đăng ký 3 Typed HttpClients riêng biệt (`CoreApiClient`, `AnalyticsApiClient`, `AiApiClient`) qua `HttpClientFactory`, xây dựng `AuthTokenDelegatingHandler` tự động đính kèm và làm mới Bearer Token trong Session, và tích hợp Polly Retry Policy cho các request GET.

---

## 2. Điểm chạm mã nguồn
- `FUNews.Client.DataAccess/Handlers/AuthTokenDelegatingHandler.cs`
- `FUNews.Client.DataAccess/Policies/PollyPolicies.cs`
- `FUNews.Client.DataAccess/Clients/` (`CoreApiClient.cs`, `AnalyticsApiClient.cs`, `AiApiClient.cs`)
- `Program.cs` (Cấu hình DI trong Frontend)
- `appsettings.json` (Cấu hình URLs của 3 API)

---

## 3. Các bước triển khai
1. Cấu hình các cổng dịch vụ trong `appsettings.json` của Frontend:
   - `ApiEndpoints:CoreApi = "https://localhost:7001"`
   - `ApiEndpoints:AnalyticsApi = "https://localhost:7002"`
   - `ApiEndpoints:AiApi = "https://localhost:7003"`
2. Xây dựng `AuthTokenDelegatingHandler`:
   - Lấy token từ Session (`HttpContext.Session`).
   - Kiểm tra hạn token: Nếu token sắp hết hạn hoặc request trả về 401 Unauthorized, tự động gọi `CoreApiClient.RefreshTokenAsync()` để lấy token mới cập nhật lại Session.
   - Gắn header `Authorization: Bearer <accessToken>` vào request gửi đi.
3. Cấu hình Polly Retry Policy:
   - Tạo policy với `HttpPolicyExtensions.HandleTransientHttpError()`.
   - Áp dụng retry tối đa 3 lần với khoảng thời gian tăng dần (1s, 2s, 4s) kèm jitter ngẫu nhiên cho các request GET.
4. Đăng ký 3 Typed HttpClients trong `Program.cs` có gắn handler và retry policy.

---

## 4. Tiêu chí hoàn thành (Acceptance Criteria)
- [ ] 3 Typed HttpClients hoạt động độc lập, gọi đúng port của từng dịch vụ.
- [ ] Gửi request tự động mang theo Bearer Token hợp lệ.
- [ ] Khi Access Token hết hạn, handler tự động gọi refresh token mà không làm gián đoạn người dùng.
- [ ] Request GET tự động retry khi gặp lỗi mạng tạm thời hoặc mã lỗi 503.
