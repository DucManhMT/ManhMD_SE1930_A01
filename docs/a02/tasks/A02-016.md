## 1. Mục tiêu
Rà soát và hoàn thiện toàn diện trải nghiệm người dùng (UX) và các yêu cầu phi chức năng (NFRs) trên toàn bộ hệ thống theo Mục 5 Đề bài: Toàn bộ form CRUD dùng Bootstrap Modals, mọi thao tác có Loading Indicator và Toast Alert, hiển thị Modal xác nhận trước khi xóa, hỗ trợ điều hướng bàn phím và độ tương phản cao, tối ưu thời gian phản hồi API < 1 giây.

## 3. Các bước triển khai
1. Loading Indicator toàn cục (Global Loading Spinner):
   - Thêm phần tử spinner ẩn trong `_Layout.cshtml`: `<div id="globalLoading" class="spinner-overlay d-none">...</div>`.
   - Viết hàm JavaScript `showLoading()` và `hideLoading()` tự động kích hoạt khi có request AJAX hoặc submit form.
2. Toast / Alert thông báo kết quả:
   - Sử dụng Bootstrap Toast Component hoặc SweetAlert2/Toastr để hiển thị thông báo góc màn hình: Màu xanh lá cho thành công, màu đỏ cho thất bại.
3. Hộp thoại xác nhận (Confirmation Prompts):
   - Thay thế toàn bộ hàm `confirm()` mặc định của trình duyệt bằng **Bootstrap Confirmation Modal** chuẩn: Hiển thị câu hỏi rõ ràng (ví dụ: *"Bạn có chắc chắn muốn xóa bài viết này không?"*), nút "Hủy" và nút "Xác nhận xóa" màu đỏ.
4. Trợ năng (Accessibility - a11y):
   - Bổ sung các thuộc tính ARIA (`aria-label`, `role="dialog"`, `aria-modal="true"`).
   - Kiểm tra điều hướng hoàn toàn bằng bàn phím (Phím Tab di chuyển hợp lý giữa các trường, phím Esc đóng modal).
   - Tối ưu màu sắc để đạt độ tương phản chuẩn WCAG (chữ đậm rõ nét trên nền sáng/tối).
5. Tối ưu hiệu năng:
   - Đảm bảo thời gian phản hồi của các API đạt dưới 1 giây (`< 1s`) qua việc phân trang hợp lý (`$top`, `$skip`) và chỉ định index trên CSDL.
