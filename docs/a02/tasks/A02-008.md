# Task A02-008 — Analytics API: Dashboard Stats, Trending & Recommend Articles

- **Trạng thái:** `DONE`
- **Phụ thuộc:** `A02-004`, `A02-005`
- **Hạng mục:** Analytics Web API

---

## 1. Mục tiêu
Xây dựng đầy đủ các endpoints phân tích và thống kê trên dịch vụ độc lập `FUNewsManagement_AnalyticsAPI`:
1. `GET /api/analytics/dashboard`: Thống kê tổng số bài viết theo category và status (kèm bộ lọc ngày, category, tác giả).
2. `GET /api/analytics/trending`: Liệt kê các bài viết được đọc nhiều nhất dựa trên bảng `NewsView`.
3. `GET /api/recommend/{id}`: Gợi ý tối đa 3 bài viết liên quan theo category hoặc tags.

## 3. Các bước triển khai
1. Xây dựng endpoint `GET /api/analytics/dashboard`:
   - Tiếp nhận query params: `startDate`, `endDate`, `categoryId`, `authorId`, `status`.
   - Tính toán và trả về DTO:
     - `totalArticles`: Tổng số bài viết thỏa mãn bộ lọc.
     - `byCategory`: Mảng thống kê `[{"categoryId": 1, "categoryName": "...", "count": 10}, ...]`.
     - `byStatus`: Mảng thống kê `[{"status": "Active", "count": 8}, {"status": "Inactive", "count": 2}]`.
2. Xây dựng endpoint `GET /api/analytics/trending`:
   - Tiếp nhận param `limit` (mặc định 10).
   - Truy vấn số lượt đọc trong bảng `NewsView`, nhóm theo `NewsArticleID`, sắp xếp giảm dần theo lượt xem.
   - Trả về danh sách bài viết kèm số view: `[{"newsArticleId": "...", "newsTitle": "...", "viewCount": 150}, ...]`.
3. Xây dựng endpoint `GET /api/recommend/{id}`:
   - Tiếp nhận `id` của bài viết đang xem.
   - Lấy thông tin bài viết gốc (Category và Tags).
   - Tìm kiếm các bài viết khác có cùng `CategoryID` hoặc có ít nhất 1 Tag chung, chỉ lấy các bài có trạng thái `Active`, loại trừ chính bài viết gốc.
   - Giới hạn trả về tối đa **3 bài viết liên quan**.
