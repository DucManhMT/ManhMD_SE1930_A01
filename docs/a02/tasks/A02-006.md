# Task A02-006 — Core API: Triển Khai Audit Logging & Ràng Buộc Toàn Vẹn

- **Trạng thái:** `DONE`
- **Phụ thuộc:** `A02-005`
- **Hạng mục:** Core Web API

---

## 1. Mục tiêu
Xây dựng cơ chế tự động ghi nhật ký thay đổi dữ liệu (Audit Logging) với đầy đủ thông tin (User, Action, Entity, Timestamp, Before/After JSON) trong cùng một SQL Transaction với thao tác CRUD, đồng thời củng cố các quy tắc nghiệp vụ chặn xóa dữ liệu có quan hệ phụ thuộc.

---

## 2. Điểm chạm mã nguồn
- `FUNews.BusinessLogic/Services/AuditService.cs`
- `FUNews.BusinessLogic/Services/` (`NewsArticleService.cs`, `CategoryService.cs`, `TagService.cs`, `AccountService.cs`)
- `Controllers/AuditLogController.cs`
- `FUNews.DataAccess/FUNewsDbContext.cs`

---

## 3. Các bước triển khai
1. Xây dựng `AuditService`:
   - Hàm `LogChangeAsync(userId, userName, action, entity, entityId, beforeObj, afterObj)` chuyển đổi object thành JSON và lưu vào bảng `AuditLog`.
   - Có thể tích hợp tự động vào override `SaveChangesAsync()` của `FUNewsDbContext` hoặc gọi tường minh trong các Services nghiệp vụ.
2. Cập nhật các thao tác CRUD:
   - Thêm mới bài viết, chuyên mục, thẻ tin, tài khoản: Ghi nhận `Action = "CREATE"`, `BeforeJSON = null`, `AfterJSON = {dữ liệu mới}`.
   - Cập nhật: Ghi nhận `Action = "UPDATE"`, `BeforeJSON = {dữ liệu cũ}`, `AfterJSON = {dữ liệu mới}`.
   - Xóa: Ghi nhận `Action = "DELETE"`, `BeforeJSON = {dữ liệu vừa xóa}`, `AfterJSON = null`.
3. Củng cố ràng buộc toàn vẹn dữ liệu (Business Rules):
   - Chặn xóa Category nếu `Category.NewsArticles.Any()`.
   - Chặn xóa Account nếu đã từng tạo bài viết (`CreatedByID == AccountID`).
   - Chặn xóa Tag nếu đang được gắn vào bài viết (`NewsTags.Any()`).
   - Chặn tạo Tag nếu tên đã tồn tại (so khớp không phân biệt hoa thường).
4. Xây dựng Controller `AuditLogController` cung cấp endpoint `GET /api/auditlog` dành riêng cho Admin (hỗ trợ phân trang và lọc theo User/Entity).

---

## 4. Tiêu chí hoàn thành (Acceptance Criteria)
- [x] Mọi thao tác thêm/sửa/xóa đều sinh ra bản ghi AuditLog tương ứng có JSON Before/After.
- [x] Hành động xóa bản ghi có quan hệ phụ thuộc bị từ chối với mã lỗi 409/400.
- [x] Endpoint `GET /api/auditlog` chỉ Admin truy cập được và trả về danh sách lịch sử chính xác.
