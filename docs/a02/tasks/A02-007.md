# Task A02-007 — Core API & FE: Upload & Hiển Thị Ảnh Bài Viết

- **Trạng thái:** `DONE`
- **Phụ thuộc:** `A02-004`, `A02-006`
- **Hạng mục:** Core API & Frontend

---

## 1. Mục tiêu
Triển khai tính năng tải lên (upload) và hiển thị ảnh đại diện cho bài viết: Kiểm tra hợp lệ định dạng và kích thước file phía Core API, lưu trữ file an toàn, cập nhật đường dẫn ảnh vào bảng `NewsArticle` và hiển thị trên giao diện Frontend.

---

## 2. Điểm chạm mã nguồn
- `Controllers/NewsArticleController.cs` (Core API)
- `FUNews.BusinessLogic/Services/MediaService.cs` hoặc cập nhật trong `NewsArticleService.cs`
- `FUNews.Client.DataAccess/Clients/CoreApiClient.cs` (Frontend)
- `Pages/News/` (Modal Create/Edit bài viết & Trang chi tiết bài viết)

---

## 3. Các bước triển khai
1. Xây dựng endpoint `POST /api/news/{id}/image` trên Core API:
   - Tiếp nhận file qua `IFormFile file` (multipart/form-data).
   - Validation chặt chẽ:
     - Kiểm tra đuôi file và Content-Type: Chỉ chấp nhận `.jpg`, `.jpeg`, `.png`, `.webp`.
     - Kiểm tra kích thước tối đa: Không vượt quá 5MB (nếu lớn hơn trả về mã 413 Payload Too Large).
     - Kiểm tra MIME type thực tế (Magic bytes).
   - Lưu trữ file vào thư mục `wwwroot/uploads/news/` với tên file GUID ngẫu nhiên để tránh ghi đè.
   - Cập nhật đường dẫn file vào cột `NewsImage` của bài viết trong CSDL.
   - Trả về JSON: `{"imageUrl": "/uploads/news/{guid}.jpg"}`.
2. Xây dựng chức năng phục vụ file tĩnh (`app.UseStaticFiles()`) trên Core API hoặc tạo endpoint stream ảnh `GET /api/news/{id}/image`.
3. Phía Frontend:
   - Cập nhật Modal Tạo/Sửa bài viết: Thêm input `<input type="file" accept="image/*">` kèm khung xem trước ảnh (Image preview) trước khi lưu.
   - Khi submit form, gọi hàm upload ảnh qua `CoreApiClient.UploadNewsImageAsync()`.
   - Hiển thị ảnh bài viết rõ nét trên Danh sách tin tức và Trang Chi tiết tin tức (`News Detail`).

---

- [x] Ảnh đại diện hiển thị đúng trên Danh sách bài viết và Màn hình chi tiết bài viết.
