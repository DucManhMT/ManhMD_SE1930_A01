- **Phụ thuộc:** `A02-002`

---

## 1. Mục tiêu
Thiết lập và chạy bản vá CSDL mở rộng cho Assignment 02 (`database/patches/005_assignment02_migration.sql`), đồng thời cập nhật các Entities và `FUNewsDbContext` trong Core API để đồng bộ với các bảng mới: `AuditLog`, `RefreshToken`, `NewsView`, `TagLearning` và cột `NewsImage`.

---

## 2. Điểm chạm mã nguồn
- `database/patches/005_assignment02_migration.sql`
- `FUNews.DataAccess/Entities/` (`AuditLog.cs`, `RefreshToken.cs`, `NewsView.cs`, `TagLearning.cs`)
- `FUNews.DataAccess/Entities/NewsArticle.cs` (Bổ sung thuộc tính `NewsImage`)
- `FUNews.DataAccess/Context/FUNewsDbContext.cs`

---

## 3. Các bước triển khai
1. Tạo file script `database/patches/005_assignment02_migration.sql` theo đúng thiết kế tại [DATABASE_MIGRATION.md](../DATABASE_MIGRATION.md).
2. Chạy script vào CSDL `FUNewsManagement` trên SQL Server.
3. Tạo các model C# tương ứng:
   - `AuditLog`: `AuditID`, `UserID`, `UserName`, `Action`, `Entity`, `EntityID`, `BeforeJSON`, `AfterJSON`, `Timestamp`.
   - `RefreshToken`: `TokenID`, `AccountID`, `Token`, `ExpiresAt`, `CreatedAt`, `IsRevoked`, `ReplacedByToken`.
   - `NewsView`: `ViewID`, `NewsArticleID`, `ViewedAt`, `VisitorIP`.
   - `TagLearning`: `TagID`, `SelectionCount`, `LastSelectedAt`.
4. Cập nhật `NewsArticle`: Bổ sung property `public string? NewsImage { get; set; }`.
5. Đăng ký các `DbSet` vào `FUNewsDbContext` và cấu hình Fluent API mapping tương ứng.
