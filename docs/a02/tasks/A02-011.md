# Task A02-011 — Frontend: Tích Hợp AI Tag Dạng Badges/Chips & Feedback Loop

- **Trạng thái:** `DONE`
- **Phụ thuộc:** `A02-010`
- **Hạng mục:** Frontend Web App

---

## 1. Mục tiêu
Tích hợp tính năng gợi ý Thẻ tin bằng AI vào Form Tạo / Sửa bài viết trên giao diện Frontend: Người dùng nhập nội dung bài viết, bấm nút "Suggest Tag", hệ thống hiển thị danh sách các tag gợi ý dưới dạng **Badges / Chips**, cho phép click nhanh để đính kèm vào bài viết và tự động gửi phản hồi (Feedback) về AI API để tối ưu Learning Cache.

---

## 2. Điểm chạm mã nguồn
- `FUNews.Client.DataAccess/Clients/AiApiClient.cs`
- `Pages/News/_CreateEditNewsModal.cshtml` (hoặc modal trong `Index.cshtml`)
- `wwwroot/js/ai-tag-suggest.js`

---

## 3. Các bước triển khai
1. Cập nhật Modal Tạo / Sửa bài viết:
   - Thêm nút bấm **"✨ Gợi ý Thẻ tin (AI)"** cạnh ô chọn Tags.
   - Thêm vùng hiển thị kết quả gợi ý: `<div id="aiTagSuggestions" class="d-flex flex-wrap gap-2 mt-2"></div>`.
2. Viết mã JavaScript (`ai-tag-suggest.js`):
   - Khi bấm "Gợi ý Thẻ tin", lấy nội dung từ trường Nội dung bài viết (`newsContent`).
   - Hiển thị spinner loading nhỏ cạnh nút bấm.
   - Gửi AJAX POST lên Page Handler hoặc gọi trực tiếp `AiApiClient.SuggestTagsAsync(content)`.
   - Khi nhận kết quả danh sách tags:
     - Render các chip dạng: `<span class="badge bg-info text-dark p-2 cursor-pointer ai-tag-chip" data-tag-id="1">#Tag (95%)</span>`.
     - Sự kiện click vào Chip: Tự động check vào checkbox tag tương ứng trong danh sách chọn của form bài viết và đổi màu chip sang xanh lá (`bg-success text-white`) để người dùng nhận biết đã chọn.
3. Khi người dùng bấm "Lưu bài viết" thành công:
   - Thu thập danh sách các tag thực tế được người dùng chọn gắn vào bài viết.
   - Gửi yêu cầu ngầm `POST /api/ai/tag-feedback` về AI API để ghi nhận feedback vào Learning Cache.

---

## 4. Tiêu chí hoàn thành (Acceptance Criteria)
- [x] Bấm nút "Suggest Tag" hiển thị đúng các tag gợi ý dưới dạng Badges/Chips kèm tỷ lệ phần trăm (hoặc confidence).
- [x] Click vào Chip tự động gán Tag vào bài viết mà không cần thao tác gõ thủ công.
- [x] Gửi feedback thành công về AI API sau khi lưu bài viết.
