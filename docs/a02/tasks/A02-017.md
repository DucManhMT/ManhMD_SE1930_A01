## 3. Các bước triển khai
1. Kiểm tra tính toàn vẹn của 4 Solutions:
   - Chạy lệnh `dotnet clean` và `dotnet build` trên cả 4 file `.sln`. Đảm bảo toàn bộ đều build thành công `0 Error(s), 0 Warning(s)`.
2. Xuất script CSDL tổng hợp `FUNewsManagement.sql`:
   - Gộp script tạo bảng gốc từ Assignment 01 cùng các bản vá mở rộng A02 (`AuditLog`, `RefreshToken`, `NewsView`, `TagLearning`, cột `NewsImage`).
   - Đính kèm dữ liệu mẫu (Seed Data) đầy đủ các tài khoản Admin, Staff, Lecturer và bài viết mẫu để giảng viên chạy là có dữ liệu ngay.
3. Cập nhật tài liệu `README.md` tại thư mục gốc:
   - Mô tả tổng quan kiến trúc phân tán 4 Solutions.
   - Hướng dẫn các bước chạy từng dự án kèm lệnh CLI chi tiết.
   - Liệt kê đầy đủ danh sách cổng mạng (Ports), Swagger URLs của cả 3 API và Web App Frontend.
   - Bảng thông tin tài khoản kiểm thử (Admin, Staff, Lecturer).
4. Chụp và lưu ảnh minh chứng vào thư mục `Screenshots/`:
   - Ảnh 1: Swagger UI của 3 API (Core, Analytics, AI).
   - Ảnh 2: Màn hình Đăng nhập & Làm mới token.
   - Ảnh 3: Màn hình Gợi ý Thẻ tin bằng AI (AI Tag Badges/Chips).
   - Ảnh 4: Màn hình Dashboard Admin với biểu đồ Chart.js (Pie & Bar) và nút Xuất Excel.
   - Ảnh 5: Màn hình Xem lịch sử thay đổi dữ liệu (Audit Log JSON).
   - Ảnh 6: Màn hình Hoạt động Ngoại tuyến (Offline Mode Banner).
   - Ảnh 7: Pop-up thông báo bài viết mới thời gian thực (SignalR Toast).
