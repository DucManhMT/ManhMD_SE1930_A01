# Task A02-013 — Frontend: Chế Độ Hoạt Động Ngoại Tuyến (Offline Mode)

- **Trạng thái:** `DONE`
- **Phụ thuộc:** `A02-012`
- **Hạng mục:** Frontend Web App

---

## 1. Mục tiêu
Triển khai chế độ Ngoại tuyến (Offline Mode) cho Frontend: Tự động phát hiện khi Core API hoặc các dịch vụ bị mất kết nối, hiển thị Banner thông báo màu vàng nổi bật trên toàn bộ các trang, chuyển sang đọc danh mục và bài viết từ bộ nhớ đệm / file JSON do Background Worker lưu trữ, đồng thời khóa cứng toàn bộ các thao tác thêm, sửa, xóa (CRUD).

---

## 2. Điểm chạm mã nguồn
- `FUNews.Client.DataAccess/Services/OfflineStoreManager.cs`
- `FUNews.Client.DataAccess/Clients/CoreApiClient.cs` (bổ sung fallback)
- `Pages/Shared/_Layout.cshtml` (Render Offline Banner)
- Các trang quản lý (News, Category, Tag, Account)

---

## 3. Các bước triển khai
1. Quản lý trạng thái kết nối trong `OfflineStoreManager`:
   - Duy trì thuộc tính tĩnh hoặc singleton: `public bool IsOffline { get; set; }`.
   - Cung cấp hàm `MarkApiFailure()` và `MarkApiSuccess()`.
2. Bổ sung cơ chế Fallback trong `CoreApiClient`:
   - Khi thực hiện các lệnh gọi GET danh sách bài viết hoặc danh mục mà ném ra ngoại lệ mạng (`HttpRequestException`, `TimeoutException`) hoặc mã lỗi 503:
     - Ghi nhận `IsOffline = true`.
     - Tự động nạp dữ liệu từ `OfflineStoreManager.GetSnapshotAsync()`.
     - Trả dữ liệu cache về cho PageModel để trang vẫn hiển thị bình thường.
3. Hiển thị Banner trên `_Layout.cshtml`:
   - Kiểm tra `OfflineStoreManager.IsOffline`.
   - Nếu đang offline, render banner thông báo:
     ```html
     <div class="alert alert-warning text-center fw-bold py-2 mb-0 border-0 rounded-0" role="alert">
         ⚠️ HỆ THỐNG ĐANG HOẠT ĐỘNG Ở CHẾ ĐỘ NGOẠI TUYẾN (OFFLINE MODE) — DỮ LIỆU ĐƯỢC TẢI TỪ BỘ NHỚ ĐỆM. CÁC TÍNH NĂNG THÊM, SỬA, XÓA TẠM THỜI BỊ KHÓA!
     </div>
     ```
4. Vô hiệu hóa các thao tác CRUD khi Offline:
   - Trên giao diện: Ẩn hoặc thêm thuộc tính `disabled` cho tất cả các nút "Thêm mới", "Chỉnh sửa", "Xóa", "Upload ảnh".
   - Phía PageModel: Trong các method `OnPostAsync`, kiểm tra nếu `IsOffline` thì từ chối xử lý, trả về thông báo lỗi: *"Hệ thống đang offline, không thể thực hiện thao tác này."*
